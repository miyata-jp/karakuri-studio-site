プライバシーポリシー

karakuri-studio（以下「本ツール」）は、YouTube チャンネル「ミヌキ【商売の裏側】」の運営者が自分のチャンネルを運営するためだけに使う道具です。

使う情報

本ツールは、Google アカウントで許可された範囲で YouTube Data API を使い、運営者自身のチャンネルへの動画のアップロード、タイトル・概要欄・タグ・サムネイル・公開予約の設定、およびその確認だけを行います。それ以外の Google ユーザーデータは取得しません。

保存と共有

ログインの情報（アクセストークン）は、運営者のパソコンの中にだけ保存します。第三者への提供・販売・広告への利用は行いません。

取り消し

本ツールへの許可は、Google アカウントの「サードパーティのアプリとサービス」からいつでも取り消せます。

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

お問い合わせ

YouTube チャンネル「ミヌキ【商売の裏側】」からご連絡ください。
